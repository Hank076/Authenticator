# app — 匯入備份版面

## 目的

匯入備份頁面在內容可放入視窗時不產生多餘的垂直捲軸；內容超過視窗時仍可正常捲動。

## 使用情境

- 使用者開啟匯入備份頁面，選擇檔案、QR 圖片或文字匯入。
- 使用者在足夠高度的視窗中檢視匯入頁面，不需要為空白外距捲動。
- 使用者縮小視窗或顯示較多內容時，仍可捲動至表單底部。

## 輸入與輸出

### 輸入

| 項目 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 視窗尺寸 | CSS viewport | 是 | 決定頁面可用高度與寬度。 |
| 匯入方式 | 字串 | 否 | 決定顯示檔案、QR 圖片或文字面板。 |

### 輸出

| 項目 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 匯入頁面 | HTML | 是 | 內容可放入視窗時不出現多餘捲軸。 |

## 資料模型

無。頁面容器結構不儲存備份資料。

## 處理流程

1. `view/import.html` 提供 ID 為 `import-app` 的 Vue 掛載節點。
2. `src/import.ts` 將 Vue 應用掛載於 `#import-app`。
3. `src/components/Import.vue` 的根節點使用 `id="import"` 並承載主題樣式。
4. `sass/import.scss` 的全頁高度與外距只作用於 `#import` 一次。
5. 頁面內容高於 viewport 時，由瀏覽器提供正常捲動。

## 錯誤處理

| 情況 | 行為 | 使用者看到什麼 |
| --- | --- | --- |
| 視窗高度小於內容高度 | 保留自然頁面捲動 | 可捲動至所有匯入欄位。 |

## 相依項目

- Vue：將匯入元件掛載至 HTML 節點。
- Sass：設定匯入頁面高度、外距與主題。

## 實作位置

| 檔案 | 職責 |
| --- | --- |
| `view/import.html` | 提供 `import-app` 掛載節點。 |
| `src/import.ts` | 掛載匯入頁面。 |
| `src/components/Import.vue` | 呈現 `import` 頁面根節點與匯入面板。 |
| `sass/import.scss` | 設定全頁高度與版面外距。 |
